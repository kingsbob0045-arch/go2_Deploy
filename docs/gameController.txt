手柄使用
注意事项：
一、 手柄在sim2sim和sim2real模式下的“使用差异”
1. 在 Sim2Sim 仿真中使用
硬件接线：手柄直接插在运行仿真节点的主机
节点启动区别：通过传递 `is_simulation:=true` 告诉状态机，手柄的指令应该发送给 MuJoCo 仿真器，而不是真实的狗（终端3/4）
ros2 rundeploy_rl_policy low_level_ctrl --ros-args -p is_simulation:=true
ros2 rundeploy_rl_policy rl_policy.py --is_simulation True

2. 在 Sim2Real 实机部署中使用
文档的最后两页（第5、6页）重点强调了实机时的手柄使用方案 ：
安全前置条件：在通过手柄控制真机前，必须首先通过手机 App 登录授权账号，连接机器狗 Wi-Fi，进入设备服务状态，手动关闭机器人自带的官方运动模式（sport_mode） 。否则手柄发出的自定义策略指令会与官方运控发生严重冲突。

 部署方案 A（连接主机部署 - 有线）：
接线：你的电脑通过网线连接 Go2 拓展坞，静态 IP 设为 `192.168.123.xxx` 。
 手柄：依然插在你的电脑/主机上。此时启动控制节点，将参数改为 `false`：
ros2 rundeploy_rl_policy low_level_ctrl --ros-args -p is_simulation:=false
 状态机会通过网线将手柄转换为实机低级控制命令（`lowcmd`）发给狗子。

 部署方案 B（机载计算平台部署 - 无线）：
接线：把代码仓库传入机器人机载的 Jetson 计算平台并完成编译 。
手柄：断开显示器和网线，手柄直接通过无线（如蓝牙）或物理方式连接到机器人机载系统上，通过手柄完全无线控制机器狗移动 。

二、 控制使用方法（Sim2Sim 与 Sim2Real 完全相同）
无论是仿真还是实机，机器人底层都由一个三状态状态机（3-state state machine）管理。你需要通过手柄按键来控制它的物理行为切换：
1. 初始状态（趴下）：
 启动系统后，机器人自动进入 Layingdown（趴下） 状态。
2. 控制起立：
 按下 O 键：机器人执行内置算法，从“趴下”切换为 Standing Up（站立） 状态。
3. 激活 RL 策略（最关键的一步）：
 机器人站稳后，同时按下 LB + RB：系统会激活你的强化学习策略节点（`rl_policy.py`），机器人开始执行推理。
操作细节：当你想要通过手柄摇杆（Sticks）自由控制机器人前后左右移动时，必须一直保持按住 LB + RB 键 
4. 切回趴下：
 按下 X 键：机器人会从站立状态切回 Layingdown（趴下）。

摇杆 Axis 索引

左摇杆：

axis 1：左摇杆左右方向
左：负值
右：正值
axis 2：左摇杆上下方向
上下方向的正负需要以当前驱动实际输出为准

右摇杆：

axis 3：右摇杆左右方向
axis 4：右摇杆上下方向

另外还有：

axis 0
axis 5

这两个是额外的模拟轴，通常对应 L2 / R2 等扳机，但具体正负方向和静止值要以当前 Linux / ROS joystick driver 的实际输出为准。图中的 axes 输出显示这些轴可能存在 -1 / 0 / 1 等特殊值，因此实现时不要假定所有轴的默认范围和方向完全一致。
